## 3. ホールドアウトの有無と人口時点による差

### ホールドアウト（対象路線の駅を除いて再校正）

- 予測の差は 1% 以内（TX 2.64 → 2.66、新横浜線 0.68 → 0.68）。
- TX のホールドアウトでは外部選択肢の定数 a₀ が −3.36 → −2.07、θ が 0.69 → 0.57 と動いたが、予測はほとんど変わらなかった。a₀ と θ・切片が互いに打ち消し合う関係にあり、個々の値は駅別の乗降データだけでは定まりにくい（校正報告の所見と同じ）。
- 1,421 駅のうち 20 駅前後を抜いても推定は安定しており、**誤差の原因は「対象路線の駅を学習に使ったかどうか」ではない**。

### 人口時点（TX: 2020 年 → 2000 年）

- 対象地域の人口は 3,845 万人 → 3,495 万人。
- 新駅の合計比は 1.33 → 1.03 と下がり、見かけ上は合う。ただし駅ごとのばらつき（対数誤差の SD）は 0.39 → 0.62 に広がる。
- **開業後に開発された駅が大きく過小になる**（2000 年人口での予測 / 実績）。
  - みらい平: 3,761 / 11,885（0.32 倍）
  - 万博記念公園: 1,731 / 7,133（0.24 倍）
  - 柏たなか: 11,049 / 16,066（0.69 倍）
  - 柏の葉キャンパス: 31,622 / 39,740（0.80 倍）
- 都心側の駅（青井・六町・浅草）は、2000 年人口でも過大のまま。
- 2000 年人口で合計が合って見えるのは、沿線開発による人口増を見込めない誤差と、都心側の過大推計が打ち消し合った結果で、精度が上がったわけではない。
- **開業前の人口だけで計画時点の予測をすると、沿線開発による需要（TX では沿線新駅の大半）を見込めない。**

## 4. 誤差の要因分析

推計を「駅勢圏の按分 → 発生・集中（μ）→ 駅間分布・経路選択」に分け、どこでずれるかを見た。
「段階 A」は、TX が既存線として存在する世界で、駅モデル（全駅校正）が TX の単独駅をどう当てているか（校正時の当てはまり）。

### 4.1 接続駅の流出入（経路転換）が最大の要因【TX】

- **規模**: 推計の輸送人員 106.5 万人/日（実績は乗降合計の半分で約 40 万人/日）の内訳は次のとおり。経路転換（既存線の駅どうしの移動が新線経由に移る分）が約半分を占める。
  - 新線内: 1.2 万人
  - 既存線と乗継: 50.2 万人
  - **既存線からの経路転換: 55.1 万人**
- **集中している駅**: 経路転換は接続駅に集中し、秋葉原（予測 57.5 万 / 実績 12.4 万）・新御徒町・南千住・北千住で 3〜7 倍になっている。
- **除いた場合**: 経路転換を除くと、接続駅の合計比は 3.43 → 1.25、路線全体は 2.64 → 1.28 になる。
- **速度との関係**: 40 km/h にすると合計比は 1.87 に下がるが、改善したのではない。経路転換が減っただけで、実際の TX はさらに速い（普通で約 61 km/h、快速 77.7 km/h）。
- **原因**: 経路転換モデル（既存経路と新線経由の所要時間差による 2 項ロジット、λ = 0.3/分、仮置き）に次の問題がある。
  1. 運賃（TX は並行路線より高い）・運行頻度・混雑を考慮していない。
  2. 既存線の表定速度が仮置きで、急行・快速がない。このため、常磐線快速などの既存経路が実際より遅く、新線が相対的に有利になりすぎる。
  3. 乗換抵抗が一律 8 分。
  4. 新線経由の流動に上限（輸送力）がない。
  5. λ を校正するデータ（経路別の OD）がない。

### 4.2 駅勢圏・発生（駅モデル）の誤差【TX の新駅】

- **全体**: 新駅 13 駅の合計比は 1.33（対数誤差 +0.18 ± 0.39）。段階 A でも 1.41 で、新線として推計した μ は段階 A の μ とほぼ同じだった（例: 六町 78,324 / 78,058）。新線の駅勢圏の按分（Huff）と μ の計算は、既存駅として校正した場合を再現できている。新駅の誤差は駅モデルそのもの（駅勢圏人口と ACC で乗降を説明する横断面モデル）の誤差である。
- **過大な駅**: 青井 2.6 倍、六町 2.2 倍、浅草 1.5 倍。いずれも足立区・台東区の都心寄りの住宅地の駅で、段階 A でも同程度に過大。考えられる原因は次の3つ（推測、未検証）。
  - バス・自転車など鉄道以外の手段との競合
  - 隣接する既存駅（綾瀬・北綾瀬、浅草〈銀座線・東武〉など）の吸引力
  - 駅間距離が短い区間での駅勢圏の重なり
- **過小な駅**: 万博記念公園 0.6 倍、つくば 0.8 倍。研究学園都市・大学の需要（通学・業務）が、従業者数だけでは表しきれないと考えられる。
- **分布段階**: 新駅の「乗降 / μ」は 0.8〜1.05 で、分布段階での増減は小さい。

### 4.3 直通運転が本質の路線は、駅の乗降では評価しきれない【新横浜線】

- **新綱島 2.4 倍**: 段階 A でも 4.7 万人と過大で、駅モデルの誤差。東横線の綱島駅（約 200m）と駅勢圏が重なり、実際には既存の綱島に利用が残っていると考えられる。開業 2 年目で立ち上がり途中の可能性もある（2023 年度 1.17 万 → 2024 年度 1.65 万）。
- **新横浜 0.5 倍**: 推計 7.7 万に対し実績 15.4 万。考えられる原因（推測を含む）は次の2つ。
  - 東海道新幹線への乗換需要が大きい。新幹線は既存ネットワークから除いているため、モデルに入らない。
  - 新横浜周辺の業務・イベント需要。
- **直通運転の効果は駅の乗降に現れない**: この路線の本質は相鉄線・東急線・JR との直通運転（乗換なしで都心へ）にある。直通客は途中駅で乗り降りしないので、S12 の駅別乗降には現れない。
  - モデル側は、直通客を「西谷・日吉での乗換（8 分）＋経路転換」として扱っている（経路転換 8.7 万人/日）。
  - その乗換客が計上される西谷・日吉は、実績が既存線と合算されていて比べられない。
  - 正しく評価するには、断面輸送量や直通運転の利用者数が必要。
- **指標の信頼性**: 比較できる駅が 2 駅しかなく、指標は参考程度。

## 5. Phase 2・Phase 3 で改善すべき点（提案）

いずれも提案にとどめる（このバックテストに合わせた調整はしていない）。

**Phase 2（交通機関タイプ・運行体系・輸送力）**

1. **既存線の表定速度を運行種別（各停・快速・急行）と運行頻度で表す**: 時刻表から速度と運行間隔を作り、待ち時間を含めた所要時間にする。既存経路が遅すぎる問題（§4.1 の 2）が直り、経路転換の過大が減る見込み。
2. **新線の運行体系**（停車パターン・本数）を所要時間と待ち時間に反映する: TX の快速・普通の違いや、ゲームの初期値 40 km/h との差がそのまま需要に効くことが §2.1 の感度分析で分かった。
3. **直通運転を運行体系の一部として表す**: 直通先の路線への乗換抵抗を 0 にし、乗換を伴わない経路にする。新横浜線のような路線の推計に必須。
4. **輸送力制約（混雑率）**: 区間ごとの輸送力の上限、または混雑による不効用で、経路転換が過大に積み上がるのを抑える。

**Phase 3（既存ネットワークを含めた経路選択・配分）**

1. **経路転換の 2 項ロジットを、ネットワーク全体の経路選択・配分に置き換える**: 一般化費用（乗車時間・待ち時間・乗換抵抗・**運賃**）を使う。TX の過大の主因（§4.1）に直接効く。
2. **経路選択の感度 λ と乗換抵抗を観測データで校正する**: 大都市交通センサス（経路別 OD）や PT 調査、断面輸送量（国交省の混雑率データ）を使う。現状は仮置きで、駅別乗降だけでは識別できない。
3. **評価指標に断面輸送量・路線別輸送人員を加える**: 直通運転の路線は駅別乗降では評価しきれない（§4.3）。
4. **新幹線との乗換**: 新横浜・品川・大宮などの新幹線駅で、アクセス需要を別途扱う。

**その他（フェーズを問わない）**

- **計画時点の予測**: 将来人口（沿線開発計画・将来人口推計）を入力できるようにする。2000 年人口では、TX の沿線新駅の需要を大きく過小評価した（§3）。
- **駅モデルの地域差**（都心寄りの住宅地での過大、研究学園・大学での過小）: 説明変数の追加（隣接駅との距離、大学・研究機関の立地など）を検討する。ただし、このバックテストに合わせた調整はしない。
- **開業初期の立ち上がり**: 開業後の年数の扱い。新横浜線は数年後の S12 で再評価する。
